# Android ASR SDK 0.3.8 升级说明

本版相对 0.3.7 改善客户会议录音的角色身份，并在 SDK 层提供完整句级角色结果。正式业务使用 Release AAR，Diagnostics 仅用于获授权的问题定位。授权、离线识别及声纹校验接入保持不变。

## 角色结果迁移

- `onSpeakerDiarizationResult.utterances` 保持原 ASR final 的完整文字和句子边界，以 `sourceUtteranceId` 关联原句。不能默认一句只有一个人。
- `speakerIndex >= 0` 表示本句可归给该人物；`speakerIndex=-1` 表示多人或不确定。`secondarySpeakerIndexes` 可记录句内观察到的角色，既可能先后说话，也可能同时说话，不能单凭该列表非空显示“重叠”。定稿的 `overlap` 和原始 `speakerTurns` 保留声学证据。
- 多人句应显示“多人／不确定”；未解决的未知应显示“不确定”。不能按多数角色覆盖全文、复制前句身份或把原句重新按每字切碎。
- `speakerInferred=true` 仍为同句内有限邻接推断，`confidence=0`；原始角色区间保留，不等于声学确认。
- 按 `windowIndex` 累积结果，提交后冻结；中间归属可修正。`isFinal` 表示句末，`isLast` 表示 ASR session 末条，角色末批使用 `isSessionFinal`。正常结束仍为唯一 last 后唯一 complete。

## 收益与范围

保留已验证的防重复建档、早期独立声源准入、局部主讲认回和未提交换人边界修正。CAMPPlus 作为端侧互补模型随包内置，不改变声纹注册和校验模型；MOSS仅用于研发辅助标注，无运行时服务依赖。

已有客户声学真机证据中，新离线录音由3个角色恢复为4个，部分同人归属和漏标改善；句级对照保持完整文字与原始角色时间线。此证据来自已记录的鸿蒙真机及缓存对照，不能替代本版 Android 最终包验收；本版实际验收见绑定最终 ZIP 的外置报告。

本轮按客户音频收益收尾。2／3／4人控制仍有0.82／0.05／13.86秒已知身份误认，部分主讲仍未知，嘈杂插话仍可能不确定；不保证所有环境均区分准确。已测鸿蒙样例实时率约0.637→0.733，结束等待1594→2083ms，用户接受该代价；Android性能以本版实测为准。Android后台／锁屏可靠性沿用未通过的限制，不计作本版修复。

本包不含 TTS 或目标说话人增强模型。
