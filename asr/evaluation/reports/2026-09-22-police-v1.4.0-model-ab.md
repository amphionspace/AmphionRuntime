# PR #218：六类警言警语的模型与增强规则配对对照

本报告的范围仅为六类 `current_police_terms*`。新增 V6 的独立模型对照已补齐，
见 [V6 完整对照](2026-09-22-police-v1.4.0-v6-model-ab.md)：默认热词下整句 78.00% → 91.25%。
下面 4,305 条的退化不能推广成“整个更新包没有收益”。

在本次 4,305 条警言警语上，**当前 PR 未证明整体精度收益**。
现有默认热词权重 3.0 下，“旧模型＋旧规则”到“新模型＋新规则”的数字格式等价整句准确率
由 82.39% 降至 81.88%，净少 22 句全对；CER 由 2.2380% 升至 2.3717%，相对增加 5.97%。
无热词时整句仅净增 2 句，CER 仍略有上升。增强规则有定向收益，但没有抵消模型替换的退化。

此前报告固定使用 1.4.0，只能证明增强规则收益，不能代表本 PR 的整体收益。
本报告补齐真正的 PR 前模型对照；不根据结果回改默认参数或筛掉失败样本。
PR 保持未合入，模型替换的精度收益仍是未解决的验收项。

## 方法

- Linux CPU，stock `sherpa-onnx==1.13.1`，两模型均固定 `zipformer2`、modified beam search、8 paths、每 recognizer 1 thread。
- 16 kHz、20 ms 分帧、endpoint 2.4/1.4/20 秒、结束补 1.2 秒；两版相同。
- 分别运行无热词、现有默认热词权重 3.0；两版预设词表完全相同，去重后 370 个词。启用热词时均为 BBPE，使用各模型自己的 `bbpe.vocab`。
- 每个 ASR segment 经同一份 WeTextProcessing 1.0.4.1 / pynini 2.1.6 和仓库 `weitn-fsts-v2`，再拼接并执行 terms → plate → station → polish。
- 增强源码与 28 个资产分别固定为 PR 前主线和当前实现。对每种热词设置计算三条路径：旧模型＋旧规则、新模型＋旧规则、新模型＋新规则。
- 新模型无热词 4,305 条全部复用，新模型默认热词复用已验证的 1,671 条行业词汇、补跑其余 2,634 条；旧模型两组各跑 4,305 条。重复数据不计为新增独立样本。
- 数字格式等价评分沿用前轮固定脚本，对参考和输出同样处理，不补号码、不把误听数字视为等价。严格口径另列。数据已用于诊断，不声称独立留出或模型训练未见过。

这是受控的主机配对对照，未运行 SDK 的完整 AGC/VAD、标点、stream 热词适配和移动端调用链。
因此不等同于真机绝对准确率；但两模型在此实验内使用同条件，不能把观察到的退化略去。
模型包同时改变训练版本和量化精度，本实验不能单独归因于 FP32 或训练更新。

## 结论与后续边界

本 PR 的规则修复可观察到小幅收益，但这份配对证据不支持把模型替换称为警言警语精度升级。
当前不应以“精度提升已验收”推进合入。此前权重 1.0 的 97.25% 仅属于新模型的行业词汇候选实验，
既未成为默认配置，也未完成同权重的旧模型对照，故不计入本次 PR 收益。

三张 ONNX 的体积约为旧版 3.34 倍；不能将体积倍数直接视为运行时内存或时延倍数。
移动端精度、ARM 资源与时延、完整 SDK 生命周期及交付包大小仍未验收。
本次仅补充评测与结论，没有再次改模型、规则、默认参数或放宽门禁。
