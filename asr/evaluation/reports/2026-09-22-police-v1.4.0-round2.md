## 代码变更与保护范围

- 将正确术语“现场勘查”加入既有词表，避免变长模糊匹配自动补成“现场勘查箱”；完整勘查箱和已有纠错保持有效。
- 在同音映射层保留“出警人员姓名”。normalize 与 polish 共用保护，原有催促语境保护和其他到场处警纠错保持不变。
- 纯数字补省，以及无明确省份/字母前缀的纯数字车牌候选，需要直接的车牌名词或明确车辆语境；“报警”“登记”等弱锚词不足以触发。设备编号仍受排除条件保护。
- 两端同步保留明确字母前缀、车主、车窗和停车位置等已有有效车牌解析。没有猜补时间、号码或增加完整句子答案映射。
- 模型、解码默认值、热词预设、SDK 生命周期和回调逻辑不变。

## 热词诊断：词表命中与整句质量必须同时看

使用现有 SDK 三类预设合并后的 370 个热词，固定 BBPE、beam=8、同一音频和分帧，
仅比较无热词、权重 3.0 和权重 1.0。先对 65 条错句及 40 条正确句诊断，再扩展到
全部 1,671 条行业词汇。1.0 是发现全量退化后的一次固定对照，不是独立留出验收。
两组热词输出都经过本轮修复后的增强代码；热词实验收益不算作本轮代码收益。

| 行业词汇指标 | 无热词固定基线 | 现有默认权重 3.0 | 候选权重 1.0 |
| --- | ---: | ---: | ---: |
| 严格整句正确 | 1,585/1,671（94.85%） | 1,532/1,671（91.68%） | 1,601/1,671（95.81%） |
| 数字格式等价整句正确 | 1,608/1,671（96.23%） | 1,556/1,671（93.12%） | 1,625/1,671（97.25%） |
| 等价口径 CER | 0.4995% | 1.4130% | 0.3639% |
| 项目词表命中 | 536/562（95.37%） | 554/562（98.58%） | 552/562（98.22%） |
| 相对无热词，字符错误减少 / 增加 | — | 19 / 74 | 17 / 0 |

权重 3.0 修复部分专业术语，却会把“防盗”偏成“防暴”、“办护照”偏成“办户政”等。
不能只拿 98.58% 的词表指标称为达标；该代理词表只覆盖 540/1,671 句。
权重 1.0 有明确后续价值，但这不是 SDK 当前默认值，也没有完成车牌、派出所、其他话术及端侧 A/B。
默认 3.0 的历史依据来自旧模型真机车牌实验，不能用当前单一词汇集直接替换全场景默认值。

以上热词实验使用 stock `sherpa-onnx==1.13.1` 的静态热词文件和 BBPE 词表，
不等同于仓库 native 分支、SDK stream 热词配置及其 AGC/VAD/标点完整调用链。
下一步应先在 SDK 对齐的推理链路中完成 3.0/1.0 跨场景对照，再决定默认值；
当前主机的 97.25% 不能宣称为真机成绩。
