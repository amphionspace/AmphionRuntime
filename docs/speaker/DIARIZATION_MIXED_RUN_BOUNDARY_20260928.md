# 公开片混合长 run 的因果分叉（2026-09-28）

**定位到当前版本的一处身份误认来源，但尚未形成可发布修复。** 155–157秒的错误来自多个窗口把换人前后的语音合成同一个 run embedding，再重复投给前一人。按一个实际观测到的声学边界重分 mask 后，同输入误认从2.07秒降至0.35秒、换号从2次降至0次；公共时间轴只改变了1.72125秒。边界仍是诊断时选出的，自动规则未验证，展示段落结构也有变化，整体交付仍 **BLOCKED**。

分析提交 `c7d65deb`，运行代码仍为 `7f8a7e4d`。本轮没有修改生产模型、SDK、窗口、hop、timeout、聚类阈值或人数规则，没有构建、安装 HAP/HAR 或重新运行整段真机音频。9个窗口的主机局部编码耗时6.81秒，不是端侧 RTF 证据。

## 最早偏离发生在 run 归属

复用180秒 AISHELL-4 四人片的保存状态，PCM SHA-256 为 `6eb6f8f41df605ec0d8e92e920f71fa17f739056f295bffb3ddf60fdc90babd7`。相对原始会议起点为690秒，正式 RTTM、10 ms、零 collar、包含 overlap 的评分不变。

1. 导出型原生重放与最后一次 SDK 聚类快照的 `hard`、`frameHard`、训练 run、AHC 和 priors 完全一致。原生组到冻结 ID 的映射为 `[3,1,2,0]`；没有证据支持“原生组正确、SDK 冻结时换错号”。
2. reference 在155.150秒从 `005-M` 转到 `004-M`。已有同 PCM 的完整 MOSS 输出也在155.180–156.620秒标为返回的第四位说话人。复用了原始标注和运行记录，没有再次请求模型；MOSS 仍是辅助证据，不是人工真值。
3. 6个较早窗口中的 run 从约151.7秒延伸至155.97–157.01秒。它们包含前一人约3.4秒、后一人约0.8–1.9秒，embedding 均更接近前一人，并作为合格长段参与训练和重建。
4. 第152窗在155.22034375秒有直接的 clean channel 0 → 1 转换。换人后的80帧短段没有独立长 embedding，保持 UNKNOWN。3个较晚窗口已经投给后一人，但在155.405秒被6个旧窗口的错误身份票压过。

因此本例不能归结为短段都没有身份、VBx 移植错误或冻结映射错误。更早的缺陷是“一个长 run 内确实换了人，但仍用一个混合向量代表整个区间”。相同物理语音的多个重叠窗口投票也不能算多份独立身份支持。

## 只改变 pooling 归属的分叉

实验开始前冻结假设、边界、9个受影响 run、可用时间、否决条件和停止条件。边界取自实际分割，不取 RTTM，但它是在查看失败状态后选出的，**不属于自动端到端政策**。

- 保持原始分割、整窗向量、模型和聚类实现不变；只在对应绝对边界拆分9个跨界 clean run。
- 每个窗口只编码一次，以同一 encoder 输出重算长子段；短子段仍为零向量，overlap 保持原样。每个子段重新计算其真实 PCM 的 RMS。
- 重算原 mask 与原向量的最大绝对差为 `5.43e-7`，通过既有数值容差，确认采用相同特征和 pooling 链路。
- 第152窗到达162秒后才允许应用补丁。保存的 Session 在170秒临时更新和180秒最终提交使用它；此前16次聚类输入及分配不变，没有把未来边界提前送入160秒预览。
- 实际执行生产 Session 的冻结、身份分配、文本对齐和提交路径。0–119.720秒已提交窗口完全不变；唯一 session final、公开对象不可改写和模拟 lease 清理断言通过。

## 调用方呈现的证据边界

使用相同 ASR token、时间戳和 endpoint，并重放实际 Demo 的结果处理和标签渲染方法。原句文字及时间范围守恒、已提交显示对象冻结；这是生产方法重放，不是新真机截图。

身份修正后，相关后一句的文字片段从“说话人1”变为“说话人4”。同时，公开段落总数由41变为42：同一原句的首个单字被独立成段，后续段落仍显示同一文字角色。原因是声学边界进入最后一个 token 起点与下一个 token 起点之间，段落时间区间覆盖两个人，而逐词归属只保留前一人。

**后续渲染审计修正：** 方法重放额外导出的 `segmentSpeakerLabel` 为“句内换人”，但实际 `Index.ets` 在 `speakerParts.length > 0` 时隐藏该摘要，直接显示文字角色。先前将此写成用户可见的“标题/文字冲突”缺少依据；不能据此新增界面缺陷。`caller-render-audit.json` 保留实际分支依据，原方法输出不删除。

声学改进还不能判为产品体验通过；同人相邻段落的合并与真实短换人的保留仍需在最终调用方验收。不能覆盖整句身份或删除短段来减少段落。没有人工听审，不因“单字”本身判定它是假发言。

首版只读评估把展示段落等同原句，因段落数量/边界变化触发断言失败。失败脚本和日志保留；V2 分别检查 ASR 对齐、按 `sourceUtteranceId` 的文字守恒和展示变化，没有修改候选输出或重复 Session 重放。

## 自动传播前先排除会破坏已有证据的规则

对四实录锚点、该公开片及三场独立校准会议做只读审计：提取“相邻帧都是单人、local channel 直接变化”的边界，不输入参考身份，不重新推理。

| 输入 | 原始直接转换数 | 会被切开的长 run | 若传播所有切点，将不再有合格长子段的原长 run |
| --- | ---: | ---: | ---: |
| 单人/UNKNOWN | 5 | 0 | 0 |
| 20秒四人 | 0 | 0 | 0 |
| 124秒四人 | 24 | 53 | 27 |
| 客户四主讲人 | 24 | 10 | 2 |
| 当前180秒公开片 | 85 | 115 | 40 |
| 校准 M | 44 | 54 | 9 |
| 校准 S | 148 | 143 | 30 |
| 校准 L | 122 | 114 | 29 |

这些是跨窗口原始转换数，不是独立真实换人数。公开片85个转换中84个至少一侧为 UNKNOWN；单人/UNKNOWN输入也有5个转换。校准 L 超过当前四人能力，只用于边界诊断。直接传播全部切点会丢失大量现有长训练证据，不能据单点收益落地；本轮没有伪称这些潜在影响已通过完整候选回放验证。

下一步自动规则必须先证明边界两侧的身份差异，处理多个窗口对同一物理边界的重复和抖动，再决定哪些 run 可以重分。可以用现有两侧长子段向量验证假设，但“两个向量最近中心不同”本身仍不是已经校准的可靠性门槛。不能把上述人工边界硬编码到 SDK，也不能继续通过任意调整时间或 cosine 阈值筛选漂亮结果。

实现时的状态不变量已明确：按 session/generation 与绝对 window/frame 标识归属；边界证据到达前不得生效；不能改写已提交结果；短段、UNKNOWN 和 overlap 必须保留；合法分帧、延迟和调度必须得到等价最终公开结果。重算或缓存 encoder 状态的实时及内存成本要单独测量，本轮尚不构成增量 encoder 迁移已完成的证据。
