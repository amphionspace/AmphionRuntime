## 更大的瓶颈在身份覆盖

用同一份原生输出，逐10 ms帧比较参考人数、重建出的全部轨迹数（含匿名）和公共已知身份数。对于参考人数 `R`、全部轨迹数 `C`、已知身份数 `K`：

```text
漏检说话人时长 = max(R - K, 0)
分割/计数重建不足 = max(R - C, 0)
已检测但没有身份 = max(R - K, 0) - max(R - C, 0)
```

逐段校验分解之和与评估器的 `missedSpeechSeconds` 完全相等。这里的时长是说话人时长；重叠中缺两人的同一秒会计两秒，不等于录音墙钟时长。

三人 AISHELL-4 中，零召回人物 `005-F` 的13.09秒参考语音只有1.60秒独说。238个训练 run 中，没有一个覆盖其独说帧，也没有纯属该人物的独说训练 run。AHC有23组、VBx剩2组是后续观测；**不能仅凭最终组数把首个错误点归为VBx**。短语音没有进入建档以及重叠身份覆盖需要分别定位，不能为了降低漏检把 UNKNOWN 填成确定身份。

## 实现约束与下一步

当前 `Model::Process` 在调用结束时释放 encoder 张量，`SpeakerDiarizationLocalClient` 会滚动清理已经消费的 PCM。主机原型保存整场 encoder 输出、在聚类时查询任意历史 mask，不能直接搬进 SDK。新增查询需明确 session/generation、绝对窗口和 mask 归属，并满足有界内存、取消/关闭时的在途调用回收；不能每次预览重复编码整场历史。

冻结边界候选保留为可进一步工程化的修复。下一步先确定有界查询实现，同时按上述损失分解定位短段准入和重叠覆盖的最早偏离点；分别用同输入状态分叉验证，避免同时修改多个状态边界。当前原型的主机耗时和缓存命中不能代替端侧 RTF/RSS，更没有证据支持宣称增量 encoder 迁移完成。

新推理路径的真实调用方呈现、全16段实录、长会议、合法调度等价性、`finish/last/complete/cancel`、离线约束，以及同一最终提交/设备/HAP/HAR交付包均未完成。没有最终 PR 或合入放行结论。
