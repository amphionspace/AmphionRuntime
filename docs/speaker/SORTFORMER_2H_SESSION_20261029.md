# Sortformer 链路两小时单会话真机实测（2026-10-29）

0.3.26 把角色分离换成 Sortformer-66M-4spk 后，按 0.3.24 的两小时口径复测温度、内存与 CPU。

## 条件

| 项 | 值 |
|---|---|
| 构建 | 最终交付 ZIP 内的 0.3.26 Diagnostics Demo（源码提交 `2d49bec5`），`--installed-package` |
| 设备 | HUAWEI VYG-AL30，HarmonyOS 7.0.0.109，亮屏前台，USB 供电 |
| 音频 | 丁桥现场 4 人录音 `100350-257`（369 s）循环 20 次拼成 7381 s 单一连续会话，20 ms 实时喂入 |
| 模式 | `diarization-windows`（识别 + 角色分离同时运行，预览 5 s 默认开启），单 cycle |
| 采样 | 压测工具每秒 RSS/HWM/线程/CPU；边车每分钟 `hidumper ThermalService`（电池/后壳/边框/系统/环境）与 `/proc` HWM |
| 起点 | 电池 26.0 °C、后壳 26.9 °C、环境 22.7 °C（0.3.24 那轮起点 31.8 °C，手机更热） |

## 结果

### 会话质量

PASS：7381 s 全部喂入，605 条 final（604 非空，9200 字），71 次角色窗口结果，说话人 4，
`degraded=0`，293 次预览更新，结束到最终角色结果 2.3 s，原生流泄漏 0。

### 内存

| 指标 | 0.3.24（Community，7332 s，同机型） | 0.3.26（Sortformer，7381 s） |
|---|---|---|
| 采样 RSS 峰值 | 1160.0 MB | **911.3 MB** |
| 内核 HWM 峰值 | 1221.5 MB | **926 MB** |
| 结束 RSS | 921.4 MB | 866.4 MB |
| RSS 斜率 | 约 2.0 MB/min | **1.13 MB/min** |
| 线程数 | — | 稳定 75（无增长） |

RSS 三段中位数 772.7 / 812.9 / 839.4 MB，HWM 每 20 分钟：791 → 822 → 856 → 867 → 888 → 948 MB。
仍是单调上升，但峰值比 0.3.24 低约 250 MB、斜率减半。增长归因（ArkTS 堆）本轮未做，
两小时内未出现回收或降级。

### CPU

整进程单核等效：均值 1.86 核，p50 1.73 核，p95 2.83 核，峰值 3.9 核（12 逻辑核）。
与 17 分钟丁桥 4 条上的 1.76 核一致，没有随会话时长上升。角色分离推理墙钟 RTF 0.28
（与识别并行的口径，和 0.3.24 的 0.126 不可直接比：0.3.24 按"窗口墙钟 / 路数"计）。

### 温度

| 传感器 | 开始 | 峰值 | 结束 |
|---|---|---|---|
| 电池 | 26.0 °C | 37.0 °C（16:12） | 36.0 °C |
| 后壳 | 26.9 °C | 36.6 °C | 36.4 °C |
| 边框 | 26.4 °C | 36.1 °C | 35.9 °C |
| 系统 | 25.9 °C | 37.9 °C | 37.6 °C |
| 环境 | 22.7 °C | 28.3 °C | 27.0 °C |

电池温升 11.0 °C / 123 min = **0.081 °C/min**（0.3.24：31.8 → 39.8 °C，0.066 °C/min）。
两点说明：起点低 6 °C 时散热差更小、斜率天然偏大；环境传感器同期上升 5.6 °C，说明机身周边
空气在升温，斜率里含环境项。绝对峰值 37.0 °C 低于 0.3.24 的 39.8 °C，也低于该客户记录到
热等级 2 的 39.1 °C，但两轮起点不同，不能据此下"更凉"的结论。

### 功耗

USB 供电下 `PowerSampler` 读到的是电池净电流（`ma=-68`，`soc=100`，`plug=2`），不是整机功耗，
与此前一致不可用。功耗仍以 CPU 时间为代理：1.86 核 × 7386 s ≈ 13 700 CPU·s。

## 结论

- 两小时单会话功能通过，无降级、无泄漏，线程稳定。
- 内存峰值和增长斜率相对 0.3.24 明显改善，但 ArkTS 堆单调上升的问题没有解决。
- 温升斜率与 0.3.24 同量级（0.08 对 0.07 °C/min），无遇热降级机制的结论不变。
