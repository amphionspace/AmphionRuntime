## 冻结的实验及否决规则

要检验的唯一行为是：尚未获得训练准入、但独占完整 clean mask 的短段，能否仅通过现有中心的 cosine 评分安全恢复身份。不改变训练成员、中心、AHC/VBx、容量选择或公开冻结规则。短段训练数、模型、窗口、timeout、ASR、文本和生命周期均不调整。

身份映射只使用已有训练 run 的参考纯净部分，按实际 10 ms 语音区间去重，进行一一映射；不使用待评价的短查询选择编号。单 run 至少 90% 的评分帧须为同一 reference speaker，且没有其他角色或 overlap，其余可以是静音。无法裁定的参考段、中心映射不纯或未映射均单列，不能当作正确身份。这里的纯度标准是外部诊断条件，不是新增的 SDK 最短语音门槛。

拒识规则预先固定为：校准集中非正确且未被容量拒绝的查询，其最高 cosine 为界限；候选仅接受严格高于界限的查询。每场校准会议必须至少恢复一条正确查询，否则在验证集推理前停止。没有分数扫描、margin 拟合或阈值回调。所有结果均为最终 prefix 的行级诊断，没有证明首次提交时可得到同样的中心。

118 行只有 58.44 秒的区间并集；重复滑窗不是独立发言。不同类别的区间也可能相交，不能把各类别时长相加当作独立错误时长。L 超过四人能力范围，只作超容量拒识诊断，不与 M/S 合并宣称能力范围内身份准确率。

冻结界限为 `0.8135216554`，三场接受的正确查询均为 0，故状态为 `REJECTED_NO_USEFUL_CALIBRATION_COVERAGE`。这个最大值来自 M 的 84.637–85.970 秒：RTTM 中 `003-F` 从 84.843 秒开始，133 个评分帧中 113 帧属于该人、20 帧无参考语音。它是边界/静音覆盖不足，**不是已经证明的身份误认**。53 条参考不确定查询进一步分为 23 条 overlap、10 条跨 reference 角色、19 条单人但静音比例超过 10%、1 条无参考语音。

即便不借助这些不确定查询，M 中也存在独立反例：

- `run=239, window=96`，97.364–98.377 秒，102 帧中 94 帧为唯一的 `002-F`，其余静音，无 reference overlap。
- 查询现有中心却以 `0.4552214536` 选择 `004-F`；正确 `002-F` 的分数为 `0.4365472026`。
- 该会议所有可确认正确的短查询最高仅为 `0.4519012487`。因此任何单一 cosine 下界都无法同时拒绝全部已确认错误、并在这场会议恢复至少一条正确查询。

这是对已冻结候选类别的否决，不是重新拟合了另一个阈值，也不是一般性的模型不可能性证明。两场四人会议仍输出四个中心，人数正确没有消除身份错误。

## 更早的偏离与后续入口

M 的对应 reference 发言为 97.436–100.501 秒，约 3.06 秒。原始第 96 窗中，181 个 reference 语音帧全部被检测为有声，但只有 55 帧为单人、126 帧被判成 overlap；clean mask 因而只留下约 1 秒给上述短查询。相邻保存窗口也存在同类 overlap 分歧，不能说是无语音或 SDK 文本丢失。

最早可见偏离是分割与 reference 对 overlap 的分歧，之后才是短向量的错误中心排序。当前证据尚未排除未标注背景声或参考边界问题，不能把两者合称为 embedding 模型能力不足；也不能通过删掉 overlap、强制单人或整体改标为多数身份来恢复指标。后续应复用这些张量，核对这段分割及短匿名轨迹的归属，再选择能隔离变量的状态分叉。

本轮检查了半开时间区间、reference 偏移、重叠、映射、完整 mask 所有权和当前候选的 UNKNOWN 状态，未改变 SDK 代码；未跑独立验证会议、四锚点、16 段或长会议。此前同产物的性能、生命周期和可读性证据继续有效，未被拼接成新的整体验收。公开精度、客户开场、长期 RSS、完整矩阵及最终同产物交付仍然阻断。
