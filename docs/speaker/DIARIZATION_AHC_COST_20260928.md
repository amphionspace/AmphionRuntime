## 根因与改动边界

当前短段备用建档只接受 `next == groups + 1 && next <= maxSpeakers`。当 `groups >= maxSpeakers`，这个条件对所有后续候选都不可能成立；`groups` 又只在准入成功时更新，所以继续遍历不可能改变训练输入。旧实现却仍为每个短段复制长历史、重新运行完整 AHC。历史和短段候选越多，无效拟合成本越高。

修复仅在该循环条件中增加 `groups < maxSpeakers`。初始未满时仍照常检查候选；刚好建满时停止后续无效拟合。没有改变中间组数与人数的既有准入政策，也没有把前序失败的“取消容量判断”候选带入生产。

保持不变：分割、特征、模型、窗口/hop、短段完整 mask 归属、训练成员、AHC/VBx 分区、最终人数上限、UNKNOWN/overlap、身份冻结、文字对齐及生命周期。明确不处理：短段身份召回、当前公开误认、长期内存和增量聚类迁移。本修复不能作为这些问题已解决的证据。
