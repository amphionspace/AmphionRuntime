# UNKNOWN 回退：用有限误认换更少 UNKNOWN（2026-09-28）

**结论：按用户决定，采用"没有 run 证据的语音回退到通道整窗声纹"。** 在 6 段公开片和 6 场从未参与设计的 AISHELL-4 会议（共 36 分钟）上，UNKNOWN 由 182.6 秒降至 2.1 秒，严格 DER 由 21.10% 降至 12.47%。合计误认 74.9 秒、同人换号 62 次，均低于官方 Community-1 的 93.5 秒、101 次，但高于当前 SDK 的 37.5 秒、36 次。有 2 段误认超过官方，逐段列于下文，**不宣称逐段达标**。

这是主机验证加鸿蒙构建的结果。改动已编译进 ZH_EN 诊断 HAP 并安装到 Mate80，但真机测试被本机另一会话的并发装包打断，**真机结果尚未取得**。角色分离整体仍为 BLOCKED。

## 用户决定与边界

2026-09-28 用户确认了以下四点，并已写入 `docs/engineering/ASR_CONTRACTS.md`（由根 AGENTS.md 按任务引用）：

1. 产品可以接受认错一些人，来换更少的 UNKNOWN，不涉及模型训练。
2. 边界是"不差于官方"，判定口径按合计。
3. 由回退找回的身份不单独标记。
4. 采用候选 1。

前序分析见[三列对照](DIARIZATION_OFFICIAL_PARITY_MATRIX_20260928.md)和[帧级归因](DIARIZATION_UNKNOWN_ATTRIBUTION_20260928.md)。帧级归因按 1.3% 的误认门槛判定时，没有任何一类 UNKNOWN 可以恢复；本轮门槛改为用户给出的"不差于官方"。

## 改动与不变量

`community_cluster.h` 的 run 模式分两步分配：

1. 原有的 run 证据分配保持不变。
2. 对没有可用 run 证据的激活通道帧（overlap 帧、未准入的短段、整通道重叠），用该通道的整窗声纹对同一组中心打分，只在该帧仍空闲的身份中分配。

保持不变：

- run 证据标签。任何帧的原有身份都不会被覆盖。
- 窗口级 `hard` 投票，即身份注册表的证据。
- 模型、窗口、hop、阈值、Fa/Fb 与人数上限。
- 已提交窗口的冻结。
- VBx 已识别、但因超出 4 人上限而未保留的声音，打分为 -inf，仍保持匿名。

**语义变化：** 从未形成身份的新声音（例如只出现在短段里、未被准入的第五个人）现在会归入最接近的已有身份。官方管线也是如此。原有 3 条"此类语音必须保持 -2"的测试断言，已改写为新的不变量："不新建身份、不成为窗口证据，但帧级有身份"。

## 被否决的候选 2

候选 2 在候选 1 的基础上，额外跳过已知混合的整窗声纹：通道 clean 帧不超过 2，或同一通道的 run 证据已出现两个身份。它的合计误认只比候选 1 少约 2 秒，同样在 AliMeeting 4 人和 M 会议 1 上超过官方，还让 AISHELL-4 2 人超出官方 0.03 秒。改进有限，却增加了规则，按用户决定不采用。
