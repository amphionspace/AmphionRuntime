# 语音识别场景划分方案 · 真机录音脚本

- 用途：按《语音识别场景划分方案》五个场景自行录音、自行检查。本稿只给"谁、在什么条件下、说什么"。
- 人物、案情、地址、号码全部虚构；号码故意用无效前缀，不要换成真实信息。
- 括号里的内容是录制提示，不要念出来。
- 每个场景先录"干净版"（按脚本、不抢话），再录"自然版"（允许插话、重叠、口语化），两版分别保存。
- 可以按自己的说话习惯微调措辞，但姓名、号码、车牌、术语、时间地点不要改，后面要对答案。

## 0. 通用录制要求

| 项 | 要求 |
| --- | --- |
| 设备 | 鸿蒙 Mate 80 与安卓 BRA-AL00 各录一遍；用 Demo 的对应场景按钮，不用系统录音机 |
| 开场 | 每条录音开头：负责人拍手一次，然后念"场景 X，第 N 遍，设备 鸿蒙/安卓"，再停 2 秒 |
| 距离 | 按各场景表格；手机屏幕朝上平放，不要拿在手里（场景四、五除外） |
| 采集源 | 按各场景表格先录推荐源；时间允许再用 MIC 补录一遍同脚本 |
| 节奏 | 两句之间自然停顿 1 秒以上；标"（停 2 秒）"的地方停满 |
| 数字 | 按逐位读法念："幺三幺"不念"一百三十一"；车牌字母按英文字母读；年份、金额、时间按口语读 |
| 命名 | `场景编号_人数_版本_设备_日期.wav`，例如 `S1A_2p_clean_harmony_20261124.wav` |
| 记录 | 每条录音配一张表：序号、说话人、开始秒、结束秒、是否重叠；用手机秒表对齐 |

角色代号固定：A 民警（主讲）、B/C/D 其他民警、P/Q/R 群众或当事人。同一人在一个场景里只扮一个角色。

## 场景一 访谈模式（2 人面对面）

| 项 | 设置 |
| --- | --- |
| 地点 | 安静办公室或接待室，关门，空调可开 |
| 摆位 | 手机放两人中间桌面，各距 0.6~1.0 m |
| 采集源 | VOICE_RECOGNITION |
| Demo 参数 | 场景"会议纪要"或"长语音"，角色分离开，maxSpeakers=2 |
| 时长 | 干净版约 5 分钟，自然版约 5 分钟 |

### 1-A 接待室报案（A 民警，P 报案人）

1. A：你好，请坐。我是今天的值班民警，姓周，工号零零幺幺。你先喝口水，不着急，慢慢说。今天过来是要报案还是咨询？
2. P：报案。我手机昨天晚上丢了，我回去想了一晚上，应该不是掉的，是被人偷走的。
3. A：好，那我们按报案流程来。先登记基本信息，我问你答，有不清楚的随时打断我。你的姓名？
4. P：林晓川。双木林，拂晓的晓，山川的川。身份证上就是这三个字。
5. A：身份证号码报一下，慢一点，一位一位念。
6. P：九九幺幺零幺，幺九九零，零三幺五，二二八七。最后一位是七，不是一。
7. A：联系电话，就用现在能联系上你的号码。
8. P：幺九九，零零零幺，二三四五。这是我爱人的手机，我自己的号码现在不在身上。
9. A：现在住址？
10. P：滨江路一百二十八号，江畔花园三栋二单元六零二。
11. A：说一下事情发生的时间和地点，尽量精确到几点几分。
12. P：昨天晚上九点四十左右，地点在滨江路地铁站 B 出口外面的夜市，就是卖烤冷面和炒粉那一排摊位的中间。
13. A：你最后一次确认手机在身上是什么时候？做了什么？
14. P：九点半左右我用手机扫码付了钱，买了一份烤冷面，十二块。付完钱我把手机放回外套右边口袋，口袋没有拉链。
15. A：然后呢？从付钱到发现手机不见，中间大概隔了多久？
16. P：隔了十来分钟。我端着东西往前走，人很多，挤了一段。走到夜市尽头想拍个照，一摸口袋，手机没了。
17. A：手机是什么品牌、什么型号、什么颜色？有没有明显特征？
18. P：黑色的，屏幕右上角有一道斜着的裂纹，大概两厘米长。手机壳是透明的，背面夹着一张公交卡。
19. A：手机号现在有没有办停机？
20. P：还没有，我想着先过来报案，怕停了以后你们查不到。
21. A：这个不冲突。我建议你出去以后马上打运营商电话挂失，再把支付软件里绑定的银行卡全部解绑。这两步比什么都重要。
22. P：好，我一会儿就办。支付软件我昨晚已经在电脑上退出了登录。
23. A：做得对。再回忆一下，当时你周围有没有让你觉得不对劲的人？
24. P：有一个穿灰色连帽衫的男的，帽子戴着，从我付钱开始就一直在我旁边，我往前他也往前。个子大概一米七五，三十岁上下，偏瘦，手里没拿东西。
25. A：他有没有和你说过话，或者碰到你？
26. P：没说话。挤的时候好像碰过一下我的右边胳膊，当时人太多我没在意。
27. A：登记表上有车辆信息，你当天是开车去的吗？车牌是多少？
28. P：开车去的，停在地铁站旁边的临时停车场。车牌是粤 B，Q 七 N 八 八 五。
29. A：停车场有没有监控，你记得入口位置吗？
30. P：有监控，入口在滨江路和临江二街的路口，收费亭旁边有一个摄像头正对着夜市方向。
31. A：好，这个信息很有用。我复述一遍你核对：报案人林晓川，昨晚九点四十左右，在滨江路地铁站 B 口夜市，黑色手机一部被盗，屏幕右上角有裂纹，疑似一名穿灰色连帽衫、身高约一米七五的男性所为，附近停车场有监控。对不对？
32. P：对，没错。还有一点，手机里有我孩子的照片，别的都无所谓，那些照片我特别想要回来。
33. A：我记下了。我现在给你做受案登记，受案回执一会儿打印给你。后面需要做一次详细笔录，大概四十分钟，你今天有时间还是改天？
34. P：今天可以，我请了一天假。
35. A：那你在外面稍等，我把登记表录完叫你。记得先把挂失和解绑办了。
36. P：好的，谢谢警官。

自然版改动：第 12 句 P 说到"九点四十"时 A 插一句"大概几点？"；第 24 句 P 说到"一米七五"时 A 立刻问"多高？"不等停顿；第 31 句 A 复述中途 P 插一句"是右上角"；最后两句两人同时说"好的""谢谢"。

### 1-B 入户走访（A 民警，Q 住户）

1. A：您好，我是咱们这个片区的社区民警，姓周，这是我的工作证。今天挨家挨户做一个反诈走访和人口信息核对，耽误您十分钟。
2. Q：进来坐吧，我正好在家。要不要换鞋？
3. A：不用，我站着说就行。先问一下，您最近一个月有没有接到自称公安、检察院、法院的电话？
4. Q：有一个，上个星期三下午。对方说我的医保卡在外地涉嫌洗钱，让我配合调查，还说要把电话转到什么经侦部门。
5. A：您当时怎么处理的？
6. Q：我觉得不对劲，公安怎么会打电话让我自己转接。我没理他，直接挂了，后来又打来一次我也没接。
7. A：您的处理完全正确。公安机关不会通过电话办案，更不会让您转账或者下载软件。凡是提到"安全账户""资金清查"的，一律是诈骗。
8. Q：那他们怎么知道我的名字和医保信息？说得有模有样的。
9. A：个人信息泄露的渠道很多，快递单、网购、各种登记表都有可能。重点不是堵住泄露，是记住三不：不转账、不透露验证码、不下载陌生软件。
10. Q：我儿子前两天还下载了一个叫"安全防护"的软件，说是银行客服让装的，装完手机就一直发热。
11. A：这个要注意，很可能是远程控制软件。麻烦让他把软件名字和下载来源发给我，我帮他看一下；如果来路不明，马上卸载并修改支付密码。
12. Q：行，他叫陈牧远，电话是幺九九，零零零二，六七八九。他今天上班，晚上回来我让他联系您。
13. A：好。接下来核对一下实有人口。家里现在常住几个人？
14. Q：三个，我、我爱人、我儿子。我爱人叫宋雨桐，儿子刚才说了。
15. A：房子是自住还是出租？
16. Q：这套是自住。楼上八零二那套是我们家的，租出去了，租给两个年轻人，做设计的。
17. A：租户的信息有没有在派出所或者物业登记过？
18. Q：好像去年刚租的时候登记过一次，后来换了一个人，新来的那个没登记。
19. A：那麻烦您把两位租户的姓名和电话发我，我这边补一下流动人口登记，不用他们专门跑一趟。
20. Q：可以。一个叫方一鸣，另一个新来的我得问一下，大概是姓谭。
21. A：没关系，您问到了再发。还有一件事，小区最近有没有陌生人频繁进出，或者楼道里堆放易燃物的情况？
22. Q：楼道还行，就是五楼有一家把电动车电池拎上来充电，我提醒过一次。
23. A：这个很危险，我回去和物业说一下，安排集中充电桩。
24. Q：那最好了，大家都担心。
25. A：好，今天就到这里。我把反诈宣传单留一张，上面有我的电话，有事随时打。
26. Q：好的，辛苦了，慢走。

## 场景二 小会议室（3~6 人围桌）

| 项 | 设置 |
| --- | --- |
| 地点 | 小会议室，空调开，允许键盘和椅子声 |
| 摆位 | 手机放桌面中心，最远的人不超过 2 m |
| 采集源 | VOICE_RECOGNITION |
| Demo 参数 | 会议纪要，角色分离开，maxSpeakers=4 |
| 时长 | 3 人版约 6 分钟，4 人版约 7 分钟，6 人版约 7 分钟 |

### 2-A 三人调解（A 民警，P 楼上住户，Q 楼下住户）

1. A：两位先坐下，水在桌上。今天把漏水的事情说清楚，咱们的目标是解决问题，不是吵架。先请楼下的说一下情况。
2. Q：我家天花板从上个月十五号开始渗水，一开始只是一小块印子，现在卫生间顶上整块墙皮都鼓起来了，走廊的灯座里也进水，灯都不敢开。
3. P：我先说一句，我家没有漏水。卫生间是去年八月刚重新做的防水，做完还做过四十八小时闭水试验，有视频的。
4. Q：那水从哪来的？总不能是我自己往天花板上浇的吧。
5. A：别急，一个一个说，都有机会讲。楼下的，渗水的位置具体在哪几个点？
6. Q：主要是卫生间顶上，靠近下水管那一侧；还有一部分在走廊，大概在卫生间门口往外一米的位置。
7. A：楼上的，你家卫生间和走廊的位置能对得上吗？
8. P：卫生间是对得上的，上下一样的户型。走廊那块对应的是我家阳台，阳台上有洗衣机和一个地漏。
9. A：阳台地漏有没有堵过？洗衣机排水管是插在地漏里还是直接排地面？
10. P：排水管是插在地漏里的。地漏堵没堵我还真没注意，平时洗衣服水都能排掉。
11. Q：你看，就是阳台的问题。洗衣机一开水就漫出来，顺着楼板渗下来。
12. A：先不下结论，渗水的原因要专业的人看。我的建议是请物业明天上门，两家都在场，先做阳台地漏的排水试验，再做卫生间的闭水试验，一次把两个可能都查掉。
13. P：可以，我明天上午在家，几点都行。
14. Q：我也在。那修的费用怎么算？我家墙皮、灯座，还有柜子顶板都泡坏了。
15. A：先查清原因，谁的责任谁承担。如果是楼上排水或防水的问题，由楼上负责维修和赔偿；如果是公共管道的问题，由物业负责；查不清的话双方按比例协商。
16. P：如果真是我家的问题，我负责修，这个没问题，我也不想天天被找上门。
17. Q：我不是故意找麻烦，我是真的没法住了。墙皮损失也得算进去。
18. A：损失部分要有依据。你先把现场照片按日期整理好，维修报价找两家，票据留好，调解的时候好算。
19. Q：照片我从十五号开始每天都拍了，有三十多张。
20. A：很好。楼上的，你把去年做防水的合同、视频也准备一下，万一要认定责任用得上。
21. P：有，我手机里就有，回头发给你。
22. A：那今天先记录：双方同意明天上午十点物业现场勘查，两家都到场；勘查结果出来后，后天下午两点再到调解室调解一次。两位有没有补充？
23. P：没有。我就一个要求，勘查的时候楼下也别带情绪，有问题说问题。
24. Q：我没有情绪，我只想赶紧修好。没有补充了。
25. A：好，那今天就到这里。调解记录我打印出来两位签个字。

### 2-B 四人案情研讨（A 主办民警，B 副手，C 法制，D 技术）

1. A：开始吧。今天过一下滨江路系列盗窃案的证据情况，目标是定下来能不能传唤、什么时候传唤。先说案件概况。
2. B：十一月以来一共七起，都在滨江路夜市周边两百米范围内，作案时间集中在晚上九点到十一点，手法都是在人群里贴身掏兜，被害人都是外套口袋或者背包外层。
3. C：七起里面有几起有视频？能不能看清人？
4. B：四起有监控，其中两起能看清正脸，另外两起只有背影和衣着，但衣着和正脸那两起一致，都是灰色连帽衫。
5. D：人脸比对已经出了结果。两起正脸指向同一个人，相似度分别是九十二和九十四，库里有两条历史记录。
6. A：身份信息说一下。
7. D：姓名赵承禹，男，三十一岁，暂住地在城东工业路附近的城中村，有两次盗窃前科，最近一次是前年。
8. C：前科材料拿到没有？要看一下上次的作案手法和判决情况。
9. D：昨天向档案室调了，今天下午能到，到了我发群里。
10. A：法制的意见，现在传唤的条件够不够？
11. C：视频加人脸比对，传唤是够的。但要立案并且后面移送，还需要至少一起案件有赃物或者资金的指向，光靠比对不行。
12. B：这个有进展。第五起被害人提供了手机串号，昨天我们在二手平台查到了交易记录，交易时间是案发第二天上午，挂牌价一千二。
13. C：交易账户的登记人是谁？
14. B：登记人叫赵承宇，禹字写法不一样，一个是大禹的禹，一个是宇宙的宇。手机号和暂住地信息对得上，应该是同一个人注册的时候用了错别字。
15. A：注意，这个细节一定要写进材料里，解释清楚为什么两个名字是一个人，别到时候因为差一个字出问题。
16. D：另外他常用的那辆电动车也查到了，车牌是苏 E，D 六 六 九 三 三，在监控里出现过三次，其中两次时间和案发时间吻合。
17. C：电动车登记在谁名下？
18. D：登记在他本人名下，去年上的牌。
19. A：好，那证据链基本能闭合。下一步分工：B 负责固定第五起的交易证据，联系平台调取账户资料；D 把三次电动车轨迹做成时间线，和案发时间一一对应；C 准备呈请传唤的审批文书。
20. C：传唤文书今天能出，审批明天上午能批。
21. B：第五起被害人明天上午九点来补笔录，顺便辨认。
22. D：时间线今晚做完，明天早上发。
23. A：那我协调办案区审讯室，后天上午八点执行传唤，同步录音录像。还有问题吗？
24. D：没有。
25. B：没有了。
26. C：补一句，涉案财物扣押清单的模板我发群里了，到时候按那个填，别用旧版。
27. A：收到。散会。

### 2-C 六人部门讨论（A 主持，B、C、D、E、F 各一段）

1. A：各位，开始周例会。老规矩，先讲上周重点，每人三分钟，讲完我汇总。B 先来。
2. B：上周出警二十三起，纠纷类十一起，占了一半；其中两起转到了调解室，一起是商铺租金纠纷，一起是停车位纠纷。
3. B：租金那起当事人情绪比较激动，第一次调解没谈拢，已经约了第二次。停车位那起当场就解决了。
4. A：租金那起第二次调解什么时候？

27. Q：好的，麻烦了。

自然版改动：第 2、3 句两人同时说；第 8 句 P 在 Q 话没说完时抢进；第 16、17 句和 19、20 句都同时说；第 24 句 P 说完 Q 紧接着说"我这边也问一下"。
