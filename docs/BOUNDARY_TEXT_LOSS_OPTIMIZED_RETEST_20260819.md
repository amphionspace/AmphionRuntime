## 9. 最终结论

1. 当前优化版没有进一步减少边界文字丢失：仍遗漏 37 字、14 个片段，CER 仍为 11.0702%。
2. 当前结果也没有退化：raw final 全文与优化前 55 秒版本逐字节完全相同。
3. 相比最初 20 秒端点，遗漏减少 64.76%、遗漏片段减少 60%、边界附近遗漏减少 64.63%的改善仍然成立。
4. 本轮代码的实际收益主要是内存有界和 native endpoint 可观测性，不涉及跨端点文本恢复算法，因此识别文字保持不变符合预期。
5. 若要继续降低剩余 37 字，需要下一阶段实现并验证跨端点重叠/上下文保留或调整模型解码，而不是继续优化队列统计。
