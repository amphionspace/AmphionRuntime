主题：Android ASR SDK 0.3.8／HarmonyOS ASR SDK 0.3.17 交付及更新说明

各位好，

本次交付 Android ASR SDK 0.3.8 和 HarmonyOS ASR SDK 0.3.17，请以完整 ZIP 及对应校验文件为准。

一、句级角色结果及接入调整

角色结果保持原 ASR final 的完整句。句内多人或重叠允许返回“多人／不确定”，请勿再按逐字角色标签切碎句子，也不要将整句强制归给一个人。请使用 sourceUtteranceId 关联原句，按 windowIndex 累积并冻结已提交结果；角色末批使用 isSessionFinal，ASR 会话末条仍使用 isLast。secondarySpeakerIndexes 非空不代表一定重叠。

二、客户录音上的改善及范围

针对现有会议音频，改善了部分同人重复建档、身份漂移和主讲漏标，原缺少的角色 4 已输出。嘈杂环境、短插话和部分身份误认仍未全部解决；本次按客户音频收益交付，不保证所有场景角色准确。详情请参见各平台验收报告与升级说明。

三、生命周期与验收

onStart 仍表示 session 已可用；isFinal 表示一句结束，isLast 表示整个识别会话的末条。普通识别由调用方 finish，正常结束为唯一 last 后唯一 complete。

两端已完成正式 SDK 和 Diagnostics 构建、包内源码独立构建及真机测试。Android Diagnostics 在测试机上出现角色降级，该角色能力及其与 Release 的一致性未通过；正式 Release 的角色 4 和完整句收益已验证。请使用正式 SDK 开展业务，不将 Diagnostics 的角色输出作为正式版准确率基准。Android 完成 50 项定向验收和 300 轮操作压力测试；鸿蒙完成 25 类发布场景与 finish 兼容性门禁。最终包已用客户录音验证句级输出与角色 4，并保留剩余精度问题、性能实测及未覆盖条件。

四、交付清单

完整 ZIP 包含正式 SDK、Diagnostics SDK、可安装 Demo、独立 Demo 源码及配套文档；另附 SHA-256、对应最终 ZIP 验收报告。正式业务请使用 Release SDK，Diagnostics 用于问题定位。本包不含 TTS 和目标说话人增强模型。

请以本次完整交付包及外置验收报告为准。
