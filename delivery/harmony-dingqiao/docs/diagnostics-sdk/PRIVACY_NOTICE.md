# 隐私说明

diagnostics 构建默认包含公共 writeAudio 输入音频和识别文本，目的是让一次复现形成完整证据。它不记录热词内容、原始 sessionId、voiceprintId、license 原文、私钥、签名材料或设备序列号。

音频不包含 SDK 内部补静音或跨 stream replay。诊断数据只保存在应用沙箱，SDK 不自动上传。电脑端收集工具会再次检查禁止字段并脱敏 hilog，但导出的 ZIP 仍可能包含业务敏感音频或文本，只应通过双方约定的安全渠道传输。

单 session 只保留最近 5 分钟音频；诊断目录总上限 200 MB，最多保留最近 3 个 run。问题结束后应按双方的数据保留策略删除手机端和电脑端诊断文件。

普通 debug 和 release 构建中诊断能力硬关闭。若现场不允许采集音频或识别文本，应使用普通构建，不应交付 diagnostics 构建。
