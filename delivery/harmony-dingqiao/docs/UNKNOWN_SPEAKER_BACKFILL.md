# UNKNOWN 邻接补全

2026-09-17，用户明确接受部分 UNKNOWN 补给相邻角色。该策略只改善文字归属的连续性，不能作为声学身份问题已经修复的证据。

## 契约

- 仅在一个可按 token 时间安全切分的 ASR 原句内处理。UNKNOWN 段必须有正时长且不超过 2500 ms。
- 句首/句尾只能继承唯一相邻已知角色；句中必须前后角色一致。全未知、不同角色之间、跨句及零时长段不补全。
- 未知段和相邻段包含 overlap 或 secondary 时不补全；即使 token 没落在某个短插话中，原始时间线中的相反已知角色也必须阻止补全。
- 依据补全前的相邻段一次性决定，不使用新推断继续扩散。原文字、来源 ID、时间范围及原始 `speakerTurns` 保持不变。
- 同角色文字合并后，只要其中有补全，`speakerInferred=true`、`confidence=0`。调用方需区分推断补全与直接声学归属。
- ITN 等无法可靠映射 token 的整句回退保持原语义；不借本次修改猜测其词级边界。

## 边界依据与局部对照

2500 ms 取自当前端侧角色推理的一个步长，限制身份外推范围；它不是声纹匹配阈值，不代表所有该时长以内的未知段一定属于相邻人。

使用既有 AISHELL-4 的 2/3/4 人连续片段各 180 秒的真实公共回调。固定完整声学时间线的全局身份映射，比较“不补、最多一步长、无限制”的已保存状态，不重新推理、不按测试词语选择规则。四人片段是 `L_R003S01C02` 的 690–870 秒，PCM SHA-256 为 `ca8dabf80f0471bb5967557f8f05669e30ca893880f34eb4df83bc77165cfbd2`。

| 候选 | 四人新增归属文字 | 新归属范围内单人参考正确时长 | 错误时长 |
|---|---:|---:|---:|
| 不补 | 0 字 | 0 ms | 0 ms |
| 最多 2500 ms | 11 字，两个原句 | 4160 ms | 0 ms |
| 不限制时长 | 71 字，三个原句 | 13690 ms | 2060 ms |

不限制时长还覆盖 170 ms 参考静音，不能以未知减少判定更好；它会把 11760 ms 的整段未知交给末尾角色。两人、三人片段没有符合条件的新增补全，作为输出不变的控制，不能称为补全准确率通过。这是有限样本的策略对照，不是正式 CER、DER 或泛化精度证明。

回归保护：姓名尾字、句首未知、同角色中间空隙、2500/2501 ms 边界、真实短回答、两个不同角色之间未知、重叠、token 间短插话、全未知、跨句和窗口提交。Harmony 与 Android 同步；真机只补一次同条件对照及必要的正常页面验证。

保留已知限制：错误的相邻声学角色仍可能传播到补全段；客户没有原始录音，当前只验证同类问题。已知身份误认仍阻断角色分离整体交付。本次不修改模型、聚类、ASR endpoint 或 VAD。
