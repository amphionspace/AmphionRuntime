# UNKNOWN 邻接补全

2026-09-17，用户明确接受部分 UNKNOWN 补给相邻角色。该策略只改善文字归属的连续性，不能作为声学身份问题已经修复的证据。

## 契约

- 仅在一个可按原生 token 时间安全切分的原始 ASR utterance 内处理；标点展示分句不能改变该边界。UNKNOWN 段不超过 2500 ms。
- 句首/句尾只能继承唯一相邻已知角色；句中必须前后角色一致。全未知、不同角色之间及跨句不补全。
- 未知段和相邻段包含已知副角色，或只有 overlap 而没有副角色来源时，不补全。仅 UNKNOWN / UNKNOWN_SECONDARY 副角色不证明主讲人换人，可保留原始重叠标记后推断。即使 token 没落在某个短插话中，原始时间线中的相反已知主/副角色也必须阻止补全。
- 句尾 token 的开始时间可能等于原句结束时间，造成零时长 UNKNOWN 尾字。只允许最后一段与前段连续、此前 2500 ms 内仍有该角色的实际声学支持且没有其它已知角色时补全；不能凭旧段落标签跨越任意长的未知区间。其它零时长段不补全。
- 依据补全前的相邻段一次性决定，不使用新推断继续扩散。原文字、来源 ID、时间范围及原始 `speakerTurns` 保持不变。
- 同角色文字合并后，只要其中有补全，`speakerInferred=true`、`confidence=0`。调用方需区分推断补全与直接声学归属。
- 先按原始 utterance、原生 token 时间及声学区间决定归属，再投影到展示分句。ITN 合并、展开、替换没有精确来源关系时，转换后的文字保留 UNKNOWN、confidence=0，原文与声学区间保留；不得用编辑距离猜测局部分句归属。

## 识别发射延迟（补全之前）

流式 ASR 的 token 时间是发射时间，晚于其声学内容。因此 token 落在所有角色区间之外时，先做一次时间基准校正，再进入上面的补全契约：

- 前一段已知角色语音在 600 ms 内结束，且该时刻只有一个角色结束，则该 token 直接归属这段语音，不标 `speakerInferred`，置信度沿用该区间。
- 只向因果方向（之前）查找，不跨越其他角色区间。前一段为 UNKNOWN、多个角色同时结束、超过 600 ms 或之前没有语音时不处理，继续按补全契约判断。
- 不改变 `speakerTurns`、ASR 公开时间戳和 2500 ms 补全边界；Harmony 与 Android 同步。

## 边界依据与局部对照

2500 ms 是此前已授权并完成局部对照的固定补全边界，限制身份外推范围；当前模型 hop 为 2 秒，二者独立；它不是声纹匹配阈值，不代表所有该时长以内的未知段一定属于相邻人。

使用既有 AISHELL-4 的 2/3/4 人连续片段各 180 秒的真实公共回调。固定完整声学时间线的全局身份映射，比较“不补、最多一步长、无限制”的已保存状态，不重新推理、不按测试词语选择规则。四人片段是 `L_R003S01C02` 的 690–870 秒，PCM SHA-256 为 `ca8dabf80f0471bb5967557f8f05669e30ca893880f34eb4df83bc77165cfbd2`。

回归保护：姓名尾字、句首未知、同角色中间空隙、2500/2501 ms 边界、真实短回答、两个不同角色之间未知、重叠、token 间短插话、全未知、跨句和窗口提交。Harmony 与 Android 同步；真机只补一次同条件对照及必要的正常页面验证。
