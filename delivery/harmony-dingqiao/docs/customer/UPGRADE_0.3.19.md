# HarmonyOS ASR SDK 0.3.19 升级说明

本版基于 0.3.18，修复 DevEco Studio 6.1 环境下集成 SDK 时出现的 `Type expected` 编译错误。该错误可导致编译器随后报告程序数量不符。

## 替换方式

1. 使用本包的 `amphion_dingqiao.har` 替换项目中的 0.3.18 HAR。
2. 同步项目依赖后重新构建，确认项目实际加载的是 0.3.19。
3. 如使用 Diagnostics SDK，整组替换对应 HAR，避免混用两版组件。Demo 源码及已签名 Demo 随完整包提供。

本次只调整 SDK 内部局部变量的命名。公共接口、默认参数、ASR 结束回调及角色结果格式均沿用 0.3.18，调用方无需修改接入代码。角色定稿默认仍为 120 秒，已有的结果累积与临时身份修正处理继续适用。

运行时版本为 0.3.19，版本日期为 2026-09-28；商用授权的维护期限须覆盖该日期。

## 验证范围

使用 OpenHarmony 6.1 / API 23 编译器复现了原错误，并验证修复后的源码可以编译；同时检查 API 26 编译及角色时间区间、重叠信息和已提交身份冻结。完整包的实际构建环境、设备检查及客户 Windows 环境未覆盖项以随包外置验收报告为准。

本版不包含 TTS 模型；目标说话人增强仅保留接口，不包含所需模型，不能启用。
