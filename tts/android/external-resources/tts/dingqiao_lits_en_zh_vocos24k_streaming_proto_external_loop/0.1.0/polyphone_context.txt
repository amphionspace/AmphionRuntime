# 多音字上下文消歧小表（运行时仅对命中的多音字查表，按字覆盖读音，不影响普通字路径）。
# 格式: 字<TAB>left<TAB>right<TAB>读音
#   left  : 目标字左侧紧邻文本需匹配的正则（以其结尾），- 表示不限
#   right : 目标字右侧紧邻文本需匹配的正则（从其开头），- 表示不限
#   一个字可写多条，自上而下首个命中者生效；规则只改该字读音，音节数不变。
