## 本次具体修改

| 修改 | 收窄后的范围 | 保护的反例 |
| --- | --- | --- |
| build 编号 | 仅在“版本 … 与／和 build 数字”的明确元数据格式中逐位读；裸 build 不再套用这条规则 | We will build 12 houses. / 120 houses. |
| 小数一点 | 只在当前汉字块中，点后剩余部分完整为数字串时保留 yi1；后接普通词时不猜测小数 | 一点三文鱼、一点五花肉、一点二氧化碳 |
| 串行 | 撤销串行这个短子串的全局默认覆盖，限定为串行完成、串行执行、串行处理 | 一串行号保留 hang2；处理保留 chu2 li3 的连读 |

| 引擎内部错误 | 完成、错误、停止分别判断：完成检查 cancelled；错误检查用户 stopRequested；所有终态仍共用同一把锁且只能提交一次 | 播放器用 cancelled 停止另一线程后仍报告原始错误；用户主动停止仍不多报 ERROR |

这是保守收窄，不是通用分词／数值来源跟踪的重写。未被明确覆盖的裸 build、孤立串行／只终止或带其他后缀的小数，回到原有默认规则，不能继续宣称覆盖所有语境。模型显式词典优先级保持原样。
