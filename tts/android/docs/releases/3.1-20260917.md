## 复现组包

Gradle stageSdkDelivery 调用 tts/tools/android/pack_sdk_only.py。应显式指定本次模型目录和模型 ID，并使用已有授权公钥构建。脚本只读取最终 AAR 和 manifest 登记的资源，排除内部导出报告，并生成清单、ZIP 与 ZIP SHA-256。不要运行旧 shell 包装脚本替代此入口。
