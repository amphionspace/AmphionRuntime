## 当前交付

AAR 包含 SDK、native 库及 IMF 170000 模型/前端。资源位于 `assets/lits-models/tts/`，SDK 首次创建引擎时按 manifest 解包、校验并加载，后续复用。工作目录中的原外置模型仍优先加载。客户 ZIP 不再重复附 external-resources；保持原有命名、接入示例及授权方式，不包含授权文件、私钥、SN 或内部报告。

本次修改资源构建和加载代码，AAR 已重新构建。公开 API 与模型推理代码未改；FP32、24 kHz Vocos、173 token、speaker 1、温度 0、两步、默认 50 帧均不变。100 帧仅用于可选覆盖值回归；常规块正数覆盖仍须 ≥40。授权兼容主版本仍为 1。
