## 当前交付

相对 3.2（2026-11-16）只修复客户反馈的中文读音问题："成都南站"的"南"读成 na。根因是主词典条目
`南站 na1 zhan4`（`南昆线 na1 kun1 xian4` 同），最长词匹配命中后逐字回退取不到正确读音。
同时补 `重做 / 重跑 / 重测 / 重拨` 为 chong2（此前缺词时按单字默认读 zhong4）；"重试"在词典里本就是 chong2，
真前端 16 种上下文都复现不出 zhong，待客户给原句。

修复只改模型包里的三个前端资源：`chinese_lexicon.txt`、由它重建的 `chinese_lexicon.bin`、运行时覆盖表 `polyphone_phrases.txt`。
模型（IMF 170000、24 kHz Vocos、173 token）、推理参数、公共 API、资源内置与解包方式、授权公钥均与 3.2 相同；
AAR 内 5 个 ONNX 与 3.1/3.2 记录逐一相同，Kotlin / native 代码无改动。

模型包不在 Git：3.1/3.2 用的包登记为 bundle `tts-runtime-imf170000-v1`（historical），本版用的登记为
`tts-runtime-imf170000-v2`（current），见 `tools/assets/manifest.json`。
