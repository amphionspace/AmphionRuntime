## Inference contract

173-token frontend, speaker 1 for both zh-en and en-US, 100 mel channels,
24 kHz Vocos, hop 384, FP32, initial-noise temperature 0. Two solver intervals
are `[0, 0.5]` and `[0.5, 1]`. The native IMF estimator embeds the start time
and interval length, with `interval_time_scale=1`. Export uses its u head;
the auxiliary v head is only used in training and is pruned from ONNX.

The condition encoder uses the training streaming attention mask on the whole
text segment. The decoder uses 50-frame chunks, separate caches per solver
step, and 20 frames of attention history. A final remainder merges into the
last block. The existing Android interval/KV model contract is reused; this
trial does not alter the SDK solver or text normalization rules.

Training-only duration statistics paths are cleared when loading. The source's
inference tone-duration clamps remain active. Weight loading is strict, and
training symbol IDs and the committed pinyin mapping are checked.

acoustic-model-only comparison.

## Export

Build the training source's `lits/utils/monotonic_align/core.pyx` extension for
the host, then export its matching Vocos with `export_vocos24k_onnx.py`.
For this source layout, add the training source root to `PYTHONPATH` when
running that vocoder exporter. Then run:

```sh
python tts/tools/android/export_improved_mean_flow.py \
  --training-source /path/to/LITs \
  --checkpoint '/path/to/step_step=00163999.ckpt' \
  --frontend-assets tts/tools/trial-export/dingqiao_lits_en_zh_vocos24k_streaming_proto_external_loop/0.1.0 \
  --vocos /path/to/vocos_vocoder.onnx \
  --output /path/to/new-bundle/0.1.0 --temperature 0
```

Build the sample with `LITS_TTS_SAMPLE_APPLICATION_ID=com.lits.tts.imfdemo`,
`LITS_TTS_SAMPLE_LABEL=Lits TTS IMF 164000`, and the matching model ID/directory
Gradle properties. Provision the external bundle and test license into this
new app's private files directory. Do not overwrite the student app.

## Validation and limits

- Strict checkpoint loading; four short Chinese/English hidden-encoder cases.
- Eleven decoder lengths (1, 39, 49, 50, 51, 99, 100, 101, 151, 350, 431)
  compared against the native IMF cached solver. Maximum mel error 0.0000319481.
- Vocos ONNX compared with the native complex-ISTFT decoder at 8/50/58/99 frames;
  maximum PCM error under 0.000083.
- SDK JVM: 148 tests, 144 passed, four existing skips, zero failures.
- TECNO KI8: six Chinese/English synthesis cases and six direct streaming
  playback requests completed without errors; first packet 378–917 ms, excluding
  model initialization. Actual model ID is asserted in the test.
- Independent-app warmup and mixed-language synthesis completed with the new
  model ID in the app log. The page-recreation test failed because the activity
  stayed STOPPED instead of RESUMED; system inspection showed the keyguard was
  showing. Rotation remains unverified in this run. See
  `validation/standalone-app.log` and `validation/keyguard.txt`.
- These are numerical and functional checks, not a perceptual quality score.
  No long stability run or full pronunciation corpus was run.
